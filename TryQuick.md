TryQuick
========

Quick examples to run the `rolling_code` binary in this repo.

Basic usage
-----------

- Minimal, single hashtag (no throttling):

```
./rolling_code -k key.secret --hashtags test --rounds 1 --interval 30 --digits 6 --throttle-min 0 --throttle-max 0
```

- Multiple hashtags (comma-separated):

```
./rolling_code -k key.secret --hashtags tag1,tag2,tag3 --rounds 1 --interval 30 --digits 6
```

- Change digits (4-digit code):

```
./rolling_code -k key.secret --hashtags test --digits 4
```

- Increase rounds (more HMAC rounds):

```
./rolling_code -k key.secret --hashtags test --rounds 1000
```

- Randomized short delays between tags:

```
./rolling_code -k key.secret --hashtags a,b,c --throttle-min 5 --throttle-max 10
```

Notes
-----
- Replace `key.secret` with the path to your key file.
- Hashtags are normalized (leading `#` added and uppercased) and required tags are appended automatically.
- If you want only one specific hashtag's output, use `--hashtags yourtag`.
