New preferences tab with 6 configurable safety features:
- 📝 **Text Mode Startup** - Optional CLI mode instead of GUI
- 🚀 **Disable Startup Tips** - Skip Getting Started guide on launch
- ✅ **Confirm Before Export** - Safety confirmation dialog before exporting
- 💾 **Auto Backup Before Save** - Automatic CSV backup before overwriting
- 🔒 **Safe Frequency Validation** - Strict frequency band checking
- ⚠️ **Channel Limit Warnings** - Alert when exceeding radio capacity
